# Logo slot

`cloudstaff-logo.png` is the full-colour landscape Cloudstaff logo (blue emblem, dark wordmark,
transparent background). It sits on a white header on every tab. Do not use the white/reversed
logo or a blue header band.

Master copies: `.claude/skills/cloudstaff-design/assets/logos/cloudstaff-logo-landscape.png`
(wide spaces such as Excel headers and slide footers) and `cloudstaff-logo-portrait.png`
(square spaces such as cover pages).
