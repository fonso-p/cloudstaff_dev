Seasonal index by custom division

with chi-square test against the company pattern
Divisions shown need at least 40 events in the selected months; divisions under 20 clients are greyed and should not be ranked. p < 0.05 = the division's monthly pattern differs from the company pattern by more than chance (chi-square goodness of fit). The test counts individual staff starts, and one client often hires several people in the same month, so very small p-values overstate the certainty: use the index and the consistency across years as the main evidence.

Statistical rules used

how to read the results
  • p < 0.05 means the difference is unlikely to be chance; above that we say "no clear difference".
  • Kruskal-Wallis compares groups without assuming normal data (net seats are skewed by a few large clients). Ties are corrected.
  • Chi-square tests whether hitting the threshold is linked to the group. 2x2 tables use the Yates correction, as scipy does.
  • Any group with fewer than 20 clients makes the result unreliable; a warning is shown.
  • Medians are shown with averages; small groups are not ranked.
  • Window-level tests count each window once; windows from the same client are not fully independent, so read those p-values as indicative. Region and division tests use one value per client (average net per window).
  • Seasonality tests count individual staff starts. One client often hires several people in the same month, so starts are not independent and very small p-values overstate the certainty. Use the seasonal index and the consistency across years as the main evidence.
  • These are associations, not causes.
  • The JavaScript results were checked against Python scipy (verify_stats.py, 6 filter settings, largest difference below 1e-6).
