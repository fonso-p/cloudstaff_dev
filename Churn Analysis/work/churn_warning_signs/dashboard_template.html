How to trace any number on the Warning signs page: the code on each bar (for example A1) is an indicator below. What counts as churn

the outcome every chart measures

1 · Indicators on the Warning signs page

each is a yes/no test at the snapshot
"How common" is the share of client-months where the sign was present. A sign that most clients have is not used in the two-signs charts, because it is the normal state rather than a warning.

2 · Features

what each client looked like at the snapshot
"Per 10 staff" divides by staff at the snapshot, so large and small clients compare fairly. Windows end the day before the snapshot, so no feature uses anything from the 3 months being predicted.

3 · Timeline columns and their sources

the file, tab and columns each one is built from
The timeline has one row per client per day with any event. The last rows are client details read straight from the engagement list (client age, region, client type).
